Privacy policy

Market Brief, last updated 12 November 2026.

Who uses it

Market Brief is a personal tool used only by its owner, on the owner's own computer. It has no other users.

What it accesses in Gmail

With the owner's permission, it uses the Gmail API to:

  • read the newsletters that the owner has filed under one label, to summarise them;
  • send one e-mail a day, the brief, from the owner's account to the same account only.

It never deletes or changes e-mails, never reads other messages on purpose, and never sends e-mail to anyone else.

Where the data goes

Everything stays on the owner's computer: the newsletters' text, the summaries and the Google login are stored locally and are never uploaded, sold or shared. To write the summaries, newsletter text is processed by the owner's own Claude Code (Anthropic) subscription, under Anthropic's terms.

Google API Services

Market Brief's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
